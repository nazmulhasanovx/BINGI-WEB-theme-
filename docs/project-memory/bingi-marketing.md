# BinGi marketing memory

## Video production
- **Workflow:** concept → script → hook → storyboard → voiceover (ElevenLabs) → assets (real software screens first) → animate → sync → edit → export.
- **Tools:** Remotion/React + FFmpeg.
- **Formats:** 9:16, 4:5, 1:1, 16:9 at 30 fps. Lengths run from 15 s ads to 60–90 s explainers.
- **Storyboard fields per scene:** number, duration, voiceover, on-screen action, asset, motion, background, SFX, text, CTA. The voiceover must match what is on screen.
- **Ecosystem film:** ~83–90 s, EN + BN. Problem → BinGi → booking sources → modules → global montage → CTA.
- **CTA:** "Create your account. Set up your property. And start your seven-day free trial today."
- **Brand lines:** "Built in Bangladesh. Designed for the world." · "One System. One Ecosystem. One BinGi."

## Script and ad style
- **Structure:** hook first — Hook → Problem → Insight → Solution → Product proof → CTA.
- **Pace:** fast, short sentences, real examples, no unverified claims.
- **Audiences:**
  - Small properties: website, online booking, basic management.
  - Medium/large properties: full HMS.

## Sales
- **Pipeline:** lead → assign → contact → requirement → demo → pricing → conversion → onboarding. WhatsApp must not be the only lead record.
- **Market focus:** Cox's Bazar, with ~1,500+ leads researched.
- **Hiring:** one sales + support person is planned.
