# BinGi Business / Commerce OS

- **What it is:** a business OS for Facebook sellers and retail shops. The name "BinGi Commerce" is proposed but not confirmed.
- **Original plan:** 17 domains, from Dashboard to Settings. Figma prompts reached ~P44.
- **Simplified direction (Oct 2026), merchant-first:** theme → colour → logo → products → publish → orders.
- **Needs:**
  - 5 storefront themes.
  - A Facebook/Instagram/WhatsApp inbox.
  - AI assistance.
  - Payment links and COD.
  - An optional own gateway or BinGi Payments.
  - SMS/email.
  - Languages: Bangla, English, Hindi, Urdu, Nepali.
- **Navigation:** Home, Orders, Products, Customers, Inbox, Website, Sales & POS, Money, Growth.
