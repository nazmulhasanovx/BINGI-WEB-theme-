 A. FOUNDER DECISIONS (final - build to these)
----------------------------------------------------------------
 1. PRICING = per room, per month (22 Nov model). No packages.
      Starter   ৳25  / room / month   (6 mo ৳23, 12 mo ৳19)
      Business  ৳70  / room / month   (6 mo ৳63, 12 mo ৳53)
      Ultra     ৳116 / room / month   (6 mo ৳105, 12 mo ৳87)
      Minimum 1 room. Capacity = number of rooms bought.
      Remove 30 / 50 / 100 / 200 room packages.

 2. ROOM TYPES BEFORE KYC
      Owner can save UNLIMITED room-type drafts during onboarding.
      KYC is needed only for: website publish, online booking, payouts.
      -> BE: remove KYC_TRIAL_CATEGORY_LIMIT for onboarding drafts.

 3. SUBSCRIPTION BEFORE KYC
      Owner can pay the BinGi subscription before KYC.
      KYC is needed only to accept online payments from guests.
      -> BE: allow subscription checkout without KYC.

 4. RESTAURANT on Business = limited version (11 Nov). Ultra = full.
      Current live behaviour is correct. No change.

 C. P0 - BLOCKERS
----------------------------------------------------------------

[P0-01] Continue from "My properties" fails
  WHERE     /onboarding -> My properties -> pick a property -> Continue
  HAPPENS   List loads fine, then error:
            "Could not load onboarding. Unauthenticated."
  IMPACT    Owner who stopped half-way cannot come back.
  EXPECTED  Continue opens the saved step. If session really expired:
            sign in -> return to the same property and step.
  FIX       BE/FE: list call and onboarding-load call probably use
            different auth (cookie vs bearer token, or scope). Make
            them use the same session.

[P0-02] "Try again" opens a different property
  WHERE     Error screen from P0-01 -> Try again
  HAPPENS   Opens /dashboard/setup-center of another property
            ("Pan Pacific Sonargaon Dhaka", 10/13 steps).
  IMPACT    Owner may edit the wrong hotel.
  EXPECTED  Retry the SAME property (or sign in and return to it).
  FIX       FE: keep property id on retry. Do not fall back to
            "last used" property.
  NOTE      Please confirm if that property belongs to the same login
            (phone number on My properties and account row differed).

[P0-03] Only the FIRST room type can be saved
  WHERE     3.2 Add rooms -> 1st type saves OK -> any 2nd type -> Save
            Tried: Garden Cottage, Private Villa, 2-Bedroom Apartment,
            Suite (Resort) and Twin Room (Hotel).
  HAPPENS   API returns:
              POST https://api.bingi.app/api/onboarding/accommodation-categories
              403 {"code":"KYC_TRIAL_CATEGORY_LIMIT",
                   "message":"Accommodation category draft cannot be saved."}
            UI shows only a generic error, hidden above the fold.
            Documents step said "Do it later" was fine.
  IMPACT    Resort cannot add cottages/villas. Hotel cannot add a 2nd
            room type. This is the main job of onboarding.
  EXPECTED  Founder decision A-2: unlimited drafts before KYC.
  FIX       BE: remove KYC_TRIAL_CATEGORY_LIMIT for onboarding drafts.
            FE: map every API error code to a plain sentence
            (KYC_TRIAL_CATEGORY_LIMIT, NOT_SUBMITTED, etc.).
  STATUS    Still active on server at 11:50, 24 Nov.

[P0-04] Checkout sells a different plan
  WHERE     2.4 Start -> Subscribe now -> Go to checkout
  HAPPENS   Page shows "BinGi Ultra - BDT 3,500"
            URL is  /onboarding/subscription-checkout?plan=PLAN_ENTERPRISE
  IMPACT    Payment order may be created for Enterprise, owner agreed
            to Ultra.
  EXPECTED  One plan id from plan step to checkout to payment.
  FIX       FE/BE: pass the selected plan id; checkout reads plan,
            rooms, period from the same source.

[P0-05] Payment blocked by KYC at the end
  WHERE     Checkout -> Continue to secure payment
  HAPPENS   Red bar: "Complete hotel KYC verification to access this
            HMS module." No gateway, no way forward.
  IMPACT    Flow pre-selected "Subscribe now" and allowed "Do it later"
            for documents, then refuses payment.
  EXPECTED  Founder decision A-3: subscription can be paid before KYC.
  FIX       BE: allow subscription checkout without KYC.
            KYC only gates online guest payments.
