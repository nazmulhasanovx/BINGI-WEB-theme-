[GLB-P1-01] Sidebar / page names are the OLD names (Sidebar v7)
  Live now                        ->  v7 name (23 Nov, founder)
  Room / Accommodation            ->  Rooms  (Accommodations when
                                      cottages/villas/apartments exist)
  Meals  (also "F&B" breadcrumb)  ->  Restaurant & Bar
  Staff                           ->  Team  (Team & HR on Ultra)
  Other Services                  ->  Services
  Discounts                       ->  Rates & Discounts
  Operations                      ->  Expenses
  Billing & Subscription          ->  Plan & Billing
  Communication Center            ->  Messaging
  Website Management              ->  Website
  Same name on sidebar, page title, breadcrumb, Cmd-K search and phone
  tab bar. Also onboarding 4.2 tool names (ONB-P2-15).

[GLB-P1-02] Errors appear out of view or not at all
  - Onboarding 3.2 save error above the fold (ONB-P1-11)
  - New booking Guest step (BKG-P1-01)
  - Services new order, error at bottom (SRV-P1-03)
  - Meals Settings 422 shown nothing (MEAL-P0-01)
  - Rooms edit 422 via browser alert (ROOM-P0-04)
  RULE: error under the field + summary at top of the visible area +
  scroll to first error. Never silent.

[GLB-P1-03] Developer / API text shown to hotel staff
  "Unauthenticated", "KYC_TRIAL_CATEGORY_LIMIT", "NOT_SUBMITTED",
  "this HMS module", "eligible legacy Room inventory", "guest
  info.booking mode is detailed", "Super Admin refund workflow",
  "snapshotted ... fee", "LEGACY-RN-33", "canonical owner", "explicit
  assignments", "Slug: qa-transport", "tsk_...", "mnt_...".
  FIX: one error-code -> plain sentence map (Bangla + English).

[GLB-P1-04] "bKash" listed twice in every payment-method list
  Same account "01867734016 - Yeapas" twice. Seen in Bookings collect
  payment, Meals POS + collect, Expenses new expense / pay / supplier
  bill. Clicking first bKash highlights the second (Meals).
  FIX: de-duplicate at source; show label + last digits; one list
  component everywhere; add Card / Nagad if enabled.

[GLB-P1-05] Native browser alert() / print dialog used
  Rooms edit error via alert() - froze the browser tab once.
  Meals "Receipt preview" opens print dialog directly.
  FIX: in-app toast / inline error; preview screen before print.

[GLB-P1-06] Screens do not refresh after an action
  Expense panel after payment (EXP-P1-03), Meals reports (MEAL-P1-03),
  Kitchen timers stuck (MEAL-P2-10), Services report (SRV-P2-12).
  FIX: use the mutation response / refetch on success.

[GLB-P1-07] Business rules enforced only in the UI
  Expense approval bypassed by API (EXP-P0-01); QR orders ignore pause
  + approval (MEAL-P0-02); onboarding checkout plan from URL (ONB-P0-04).
  RULE: every rule (approval, limits, pause, plan, KYC) checked in the
  backend endpoint, UI only hides the button.

[GLB-P1-08] Two sources of truth for the same thing
  Room state legacy vs accommodations (ROOM-P0-01..05, BKG-P0-01/03);
  OOO Housekeeping vs Rooms (HK-P0-01); expense status vs payments vs
  Cashbox (EXP-P0-03/04); outstanding Reports vs Bookings (MON-P1-01);
  floors Setup vs Rooms vs Housekeeping (ROOM-P1-08, HK-P1-02).
