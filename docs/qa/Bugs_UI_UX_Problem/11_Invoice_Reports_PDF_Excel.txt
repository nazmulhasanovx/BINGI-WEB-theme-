 PROFESSIONAL STANDARD  -  build every document to this
================================================================

 S1. ONE DOCUMENT SYSTEM (shared by every module)
 +--------------------------------------------------------------+
 | HEADER  hotel logo | legal name | address | phone | email |   |
 |         BIN (if set)                  DOC TITLE + Bangla sub |
 |                                       No. / date / ref / chip|
 |--------------------------------------------------------------|
 | BODY    2 info boxes (who / what) -> line table -> totals    |
 |         -> payments -> notes from Settings                   |
 |--------------------------------------------------------------|
 | FOOTER  thank-you line | "Powered by" + official BinGi logo  |
 |         page x / y (repeats on every page, header row too)   |
 +--------------------------------------------------------------+
  - A4 portrait for guest documents, A4 landscape for wide reports,
    80 mm thermal for counter receipts.
  - Font: Inter (Latin) + Noto Sans Bengali (Bangla), subset.
  - Colour: ink #1D2433, grey #6B7385, lines #E3E6EC, brand red
    #B11C29 for the title and one accent only. No dark fills.
  - Money: ৳ + lakh grouping, numbers right-aligned, tabular figures.
  - Bilingual: English labels with small Bangla sub-labels (or a
    language switch per hotel in Settings).
  - Size < 300 KB, generated < 2 s, file name
    <Hotel>_<Document>_<No-or-Date>.pdf
  - Same data service for screen, PDF, Excel, CSV (DOC-P1-09).

 S2. WHICH DOCUMENT, WHEN
   Booking confirmation / Proforma  when booked      no invoice no.
   Payment receipt                  each payment     RCP-0001
   Folio (running bill)             any time in house
   Invoice                          at check-out     INV-0001, no gaps
   Credit note / Refund receipt     refund, cancel   CRN-0001
   Contract / Registration card     at check-in      ID + signature
   Restaurant / Service receipt     each order       80 mm
   Expense voucher                  each expense paid
   Cashbox day report (Z)           day close        signed counts
   Purchase order                   to supplier      PO-0001

 S3. INVOICE MUST SHOW
   Hotel block + BIN | Invoice no., issue date, booking no. | Bill to
   (name, phone, email, company + its BIN if corporate) | Stay (dates,
   nights, guests, room no. + category) | Lines: description, details,
   qty, rate, amount | Subtotal, discount, service charge %, VAT %,
   Total | Payments table (every payment) | Paid, Balance due | Notes
   and policy from Settings | "Computer-generated, no signature".

 S4. REPORT PDF MUST SHOW
   Hotel + report name + date range + generated at/by | 4-5 KPI boxes
   that fit the page | full table, header row repeats each page,
   grand total only at the end | small summary tables | footer with
   page x/y. No placeholder text.

 S5. EXCEL MUST BE
   Sheet 1 "Summary" (totals as FORMULAS pointing to the data sheet),
   Sheet 2+ data tables: header in row 1, frozen, filter on, numbers
   as numbers with ৳ format, dates as dates, real names (guest, staff),
   one spelling per method, column widths set, print = fit to 1 page
   wide + header/footer, "Read me" sheet with what is counted.

 S6. CSV MUST BE
   UTF-8 with BOM, readable headers, ISO dates, plain numbers (no ৳,
   no commas), one row per item, no internal IDs unless asked.
