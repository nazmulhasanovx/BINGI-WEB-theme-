---------------- P1 ----------------

[SRV-P1-01] New scheduled order goes straight to "Active"
  WHERE     New Service Order -> Schedule (tomorrow), nobody assigned
  HAPPENS   Board shows it in "Active - open work to deliver".
            Edit Order shows status = Active.
  EXPECTED  Future + nobody assigned = "Scheduled".
            Assigned, not started = "Assigned".
            Started = "Active".
  FIX       BE: default status from requested time + assignee.

[SRV-P1-02] Order details has only "Mark done"
  WHERE     Click an order card -> Order Details
  HAPPENS   Buttons: Close, Edit Order, Mark done.
            No Assign, no Start. Assign only inside Edit Order.
  EXPECTED  Assign (pick staff) and Start buttons in details, same
            steps as the board: Assign -> Start -> Done.

[SRV-P1-03] Save errors are hidden at the bottom of the form
  WHERE     New Service Order -> Save
  HAPPENS   "Order not confirmed - Open today's cashbox ..." and
            "QA Car 1 is already booked 10:00-11:00 ..." appear
            below the total, out of view. Looks like Save did nothing.
  EXPECTED  Error shown at the top of the visible area (or toast),
            and the form scrolls to it.

[SRV-P1-04] Cash sale only: no "pay later", only cash
  WHERE     New Service Order -> Cash sale
  HAPPENS   A walk-in order scheduled for tomorrow must be
            "Cash sale - paid now" and needs today's cashbox open.
            No bKash / Nagad / card choice.
  EXPECTED  Walk-in: Pay now (cash / bKash / Nagad / card) or
            Pay when done. Booking guests: Charge to booking.
            Info box should say up front if the cashbox is closed.

[SRV-P1-05] No "Charged per" and no child price
  WHERE     Add Service
  HAPPENS   Only one "Unit price". Quantity on the order has no
            meaning (person? trip? hour?).
  EXPECTED  Charged: each / per person / per trip / per night /
            per hour / per piece. Child price when per person.
            (prototype)

[SRV-P1-06] Two durations that disagree
  WHERE     Add Service with a resource
  HAPPENS   "Duration shown" is free text ("1 hour") and
            "Book the resource for (minutes)" says "Empty means 80".
            Catalog shows durations as "20", "2" with no unit.
  EXPECTED  One duration in minutes (picker: 30 min, 1 h, 2 h...).
            Resource is booked for that time. Show "1 h" in catalog.

[SRV-P1-07] No "New requests" column for guest requests
  WHERE     Today board
  HAPPENS   Columns: Scheduled, Assigned, Active, Done.
  EXPECTED  Prototype: New requests (from guests - accept / decline),
            To assign, Assigned, In progress, Done.
  NOTE      Please confirm if Guest App / website can request a
            service today. If yes, this column is needed.
